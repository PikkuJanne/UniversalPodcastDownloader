# UniversalPodcastDownloader v1.0.0

The first stable release of the completed portable Windows RSS/Atom podcast downloader.

Download `UniversalPodcastDownloader-1.0.0.zip`, `manifest.json` and `SHA256SUMS` together. Verify the checksums, extract the ZIP into a new directory, and keep both launchers with the complete `src` directory. Double-click `UniversalPodcastDownloader.bat` for the guided interface, or run the PowerShell script directly. Read the packaged README for commands and recovery guidance.

## Included

- Latest, Custom and All modes with configurable output and original audio bytes.
- Bounded feed discovery and catalogue traversal, stable episode identities, Windows-safe paths and verified download history.
- Conservative legacy review and resume of strictly owned, checkpointed partial transfers.
- Private run results and exit codes, sequential saved-show batches with Windows CurrentUser DPAPI credential protection, interactive byte progress and opt-in temporary keep-awake.
- Both entry points, all 27 runtime helpers, original MIT license and artwork, README, changelog and release guide. Personal settings, credentials, downloaded media, archive state, logs and development tools are excluded.

Windows PowerShell 5.1 and PowerShell 7 on Windows are supported. The application requires no Python, Git, FFmpeg, package manager, cloud account or background service. The script is unsigned; the batch launcher applies execution-policy bypass only to its child process and does not change machine or user policy.

## Verification and limits

The manifest identifies the exact committed source/tree and every payload file's size and SHA-256. The identical manifest is embedded in the ZIP; `SHA256SUMS` covers the ZIP and sidecar manifest. Checksums establish byte consistency, not publisher authentication.

The runtime is unchanged from the completed development project and its retained acceptance evidence. New stable-version packaging checks, two-engine CI and independent package verification are recorded against the selected release source. Historical human Explorer and physical Ctrl+C observations retain their original candidate and Windows Sandbox engine bindings.

All covers the bounded accessible catalogue rather than every episode a publisher has ever produced. Container checks do not decode an entire recording. DPAPI does not protect against compromise of the Windows user/admin account or recorded input. Private URLs can enter shell history or transcripts. Preserve archives, state and partials; uncheckpointed partial tails require review. Host sleep/lid behavior, hard-kill/power-loss cleanup and network-share durability are not guaranteed.

Website assets and deployment remain a later project.
