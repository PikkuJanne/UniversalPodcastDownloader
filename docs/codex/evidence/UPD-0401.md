## Final architecture and acceptance

- Shared retry waiting reuses the operation owner's observed clock, retains rounded server delays, remaining-budget checks and nonadvancing/oversleep handling. Only helper-created Deferred failures carry the supplied Attempts; injected exceptions retain their original object/data. Existing oversleep/nonadvancing cases now assert Deferred and Attempts1 as well as no early retry.
- Saved option routing and strict primitive validation use the same11-name allowlist, preserving range/type/selection restrictions. Configuration is never permissively splatted.
- Diagnostics finally clears the same existing URL-to-ID dictionary without creating new state on pristine close. Bounded export context/events and preview latch survive. Clearing references is not whole-process string zeroing; attempted cleanup through a faulty Dispose is not a universal release promise.
- Guided typed metadata cancellation now reaches the existing cancellation130 path without reprompt. Internal Write-Log is replaced by the existing diagnostic writer; title lookup's best-effort catch uses fixed private verbose guidance and preserves typed cancellation.
- [ARCHITECTURE](../ARCHITECTURE.md) documents actual27 src files,24 direct imports/three transitive unique files, public run/command/batch contracts and resource ownership. Management/batch projections omit paths; a private named RunResult may retain sensitive LegacyResult inventory. Imported helpers remain internal testing seams, with explicit fresh defaults.
- HTML link whitespace/URI dedupe, original feed identity, pagination aliases and resume fingerprints remain separate because their contracts differ. Bounded8MiB metadata and streamed media share transport policy while retaining distinct ownership/validation rules. No duplicate alternative downloader engine was introduced.
- Audit retained35 scoped runtime suppressions: in-memory factories/plans, caller-confirmed transaction/probe/native ownership, stable API helper names/collection interfaces and lookup-only legacy SHA1. Justifications remain adjacent to the narrow scope. Existing WriteHost exclusion applies to ConsoleHost UI; all other default Warning/Error rules remain enabled. D081-D085 record choices.
