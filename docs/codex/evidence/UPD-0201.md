## Implementation

- Add import-safe `src/TransportPolicy.ps1`, shared by metadata and media through NetworkPolicy. Six validated script options configure attempts, header and idle timeouts, retry window and exponential backoff.
- Use `ResponseHeadersRead`, bounded task waits, cancellation and disposal; disable HttpClient's implicit total timeout. Healthy long body reads remain allowed. Retry budget controls another attempt or delayed redirect, and cannot be reset by each redirect/attempt.
- Retry HTTP 408/429/500/502/503/504 and classified transient connection/timeout/incomplete-body failures. Stop permanent HTTP/TLS/policy failures, invalid content and local filesystem/history failures. Server Retry-After seconds/dates and redirects honor minimum delays; over-budget/overflow delays defer. Inject clocks/waits for unit checks.
- Retry metadata from empty memory. Retry recorded media through fresh owned temporary transactions with unchanged prepared evidence and no-overwrite placement. Remove the unconditional fixed main loop; legacy explicit redownload uses the same policy.
- Preserve private diagnostics with fixed category messages, safe in-memory failure metadata and accurate attempt counts. Resolve propagates typed metadata failures so deferred requests are reported. No new state schema, resume, range request, dependency or background scheduling.
