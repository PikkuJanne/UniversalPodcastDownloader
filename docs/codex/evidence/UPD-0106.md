## Implementation

- Initialize unique UTF-8 logs before discovery in local application data, with temporary-directory fallback and safe stderr if neither destination is writable. Root/show safety checks and CreateNew preserve existing data. Best-effort init, append, archive-switch, close and CLI export failures do not replace the operation error.
- Keep up to 256 recent in-memory events. Confirmed normal downloads open a correlated log in the existing show and retain the initial startup copy. Logs use UTC and random GUID run IDs. Valid non-BMP Unicode survives UTF-8 round trips.
- Display only host and random per-run URL ID; retain original request values for network use. Suppress internal web-cmdlet verbose/debug/progress. Diagnostic output omits untrusted titles, local paths, raw publisher IDs, URLs, headers, body text and unknown exception messages. Exact allowlisted application instructions remain actionable; an injected suffix is rejected.
- Preserve the original exception instance behind a fresh public ErrorRecord with safe ErrorDetails. Normal WhatIf returns a small projection without Episode/StateRecord internals. The exact local legacy inventory remains owner-review data, explicitly excluded from sharing/export.
- Optional DiagnosticExportPath writes a new JSON from typed run metadata and fixed event timestamp/level/code fields. It never reads logs or copies runtime/state/config/history/checkpoint/media objects. Failed export preserves success or the primary failure.
- Preview/WhatIf suppress all diagnostic files and exports. Explicit confirmation buffers until acceptance, then starts a fresh context. Declined confirmation remains unwritten. Original entry points, archive bytes, schemas, locks and no-overwrite rules stay intact.
- DIAGNOSTICS.md documents retained startup copies, owner-managed deletion, sensitive older logs, private local review objects and caller/host limitations. No upload, cleanup daemon or runtime dependency.

## Limits and handoff

Logging is best effort; a hard crash or unavailable disk can leave incomplete or absent logs. Concurrent creation of a diagnostic directory can fail closed and use fallback/stderr. Logs retain hosts and episode fingerprints for local review; exports omit both. Legacy inventory, archive filenames/history, callers inspecting original exceptions, shell history/transcripts, parameter binding and source-loading failures remain outside the restricted export. Earlier logs are preserved and never ingested. No automatic pruning, network/XML hardening, retries/resume or launcher changes are claimed. A022-A060 remain not_run.
